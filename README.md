# Syed Talha Shakeel - Portfolio

A modern, interactive, and sleek portfolio website built to showcase my backend engineering projects, technical skills, and certifications. 

## 🚀 Live Site
*(Will update this link once deployed to Cloudflare)*

## ✨ Features
- **Interactive UI:** Custom cursor spotlight, 3D tilt project cards, and text scramble effects.
- **Apple-style Layout:** Sticky stacking project cards for a premium scrolling experience.
- **Fully Responsive:** Optimized for desktop and mobile viewing.
- **Working Contact Form:** Powered by Formspree.
- **Scroll Animations:** Custom IntersectionObserver-driven stagger effects.

## 💻 Tech Stack
- **Framework:** [Astro](https://astro.build/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Language:** TypeScript / JavaScript
- **Components:** React (for interactive elements like `LetterGlitch` and `SkillsList`)
- **Deployment:** Cloudflare Pages
